This plugin is being developed for the IndiaMediaLens Project: Targeted Sentiment Analysis for Political Tone Identification in Indian News Media. 

It is supported by the Mphasis AI & Applied Tech Lab at Ashoka and the Vachani School of Advanced Computing.

# Installation
This extension is yet to be published to the Chrome Web Store. Once it is, it should be downloadable as any other chromium extension.

To download from this repository, proceed as follows:


1. Press Download ZIP under the Code tab in this repository.
<img width="934" height="561" alt="image" src="https://github.com/user-attachments/assets/38b0dc85-8da9-4b6a-90fd-5771b2cdbcc4" />

2. Once downloaded, extract the ZIP to a directory of your choice. You may delete the ZIP file after this.

3. Now, navigate to `<your_chromium_browser_name>://extensions/` and enable developer mode.

4. Click 'Load Unpacked' and navigate to the folder named `ViewFinder` saved in the earlier directory. Open this folder - this should load the Extension to your chromium browser.
